# 🏥 MediTrack – Healthcare Management System

MediTrack is a role-based hospital management system built with Laravel that helps clinics efficiently manage their operations and patient care.

## 📋 What MediTrack Does

It helps clinics manage:

- 👨‍⚕️ Doctors
- 🧑‍🦽 Patients
- 📅 Appointments
- 💊 Prescriptions
- 🧪 Lab Tests

---

## 🚀 Features

- ✅ **Secure Authentication System** – Login, register, and logout with password security
- ✅ **Role-Based Dashboards** – Admin-ready dashboard system for different user roles
- ✅ **Full CRUD Operations** – Complete Create, Read, Update, Delete for all hospital modules
- ✅ **Search Functionality** – Quick search across doctors, patients, appointments, prescriptions, and lab tests
- ✅ **Clean UI** – Professional Bootstrap 5 interface for smooth user experience
- ✅ **Real-Time Statistics** – Dashboard with live hospital metrics

## 🚀 Quick Start

Get MediTrack running on your local machine:

```bash
# Clone the repository
git clone https://github.com/adventureibtisam111/meditrack.git
cd meditrack

# Install dependencies
composer install

# Setup environment
cp .env.example .env
php artisan key:generate

# Setup database
php artisan migrate

# Start the development server
php artisan serve
```

Visit `http://localhost:8000` in your browser to access MediTrack.
